# Architecture

`src/main.c` parses arguments through `src/cli/args.c`, then delegates to
`src/cli/run.c`. The release is a C17 executable; it does not invoke tests
or Python at runtime.

The pipeline is parse → scan/cache → metadata/corpus/workspaces →
catalog/priority/pricing → payload/page:

| Modules | Role |
| --- | --- |
| `src/parse/`, `src/model/` | Stream JSONL into log records, turns, messages, tools, links and usage observations. |
| `src/scan/`, `src/cache/` | Discover logs, reuse or reparse native cache entries, stage and commit cache updates. |
| `src/meta/` | Load Codex metadata through read-only SQLite connections. |
| `src/acct/` | Track token totals, classify rollouts and resolve inherited fork baselines. |
| `src/corpus/` | Assemble sessions, titles/status, subagent relationships and workspace aliases. |
| `src/price/` | Fetch/cache catalog, validate and record history, retain priority evidence, compose usage and dated costs. |
| `src/out/` | Serialize payload and embed it in the offline page. |
| `src/cli/`, `src/util/` | Coordinate lifecycle, progress, browser/summary, atomic I/O, events, Unicode and stable sort. |

Catalog work starts before scanning and joins before pricing. The CLI reads
ledger state and detects edits before appending newly observed rates; this
does not eliminate the concurrent read/replace race. Rendering precedes
cache commit. Cleanup joins catalog work before freeing shared resources.

`tools/embed.pl` embeds `assets/` into build-generated C. Page shell, CSS,
JavaScript, Martian Mono font subsets and their notice, public curated rate
seeds, and Unicode 17 pricing-property ranges ship in the executable.
Unicode 16 normalization/casing tables are committed in `src/gen/` and are
not regenerated by make. yyjson 0.13.0 is vendored in `vendor/yyjson/`.
Production includes retain minimal `src/testing/` support headers; release
test hooks are inactive unless compiled with `COLOPHON_TESTING`.

The fresh test harness independently checks synthetic behavior and retained
C units. The original captured-corpus parity/performance machinery is not
part of this project. See [development](development.md) for its validation
boundary and [third-party notices](../THIRD_PARTY.md) for provenance.
